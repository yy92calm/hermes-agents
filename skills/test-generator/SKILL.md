# 测试生成技能

## 功能

分析目标代码的函数签名、输入输出类型、分支逻辑，生成结构化的测试用例，覆盖正常路径、边界条件和异常场景。

## 工作流程

### 1. 分析目标代码
- 读取函数/方法的签名（参数、返回值、装饰器）
- 识别分支逻辑（if/else、match/case、try/except）
- 理解外部依赖（数据库、API、文件系统）

### 2. 生成测试矩阵

| 类别 | 覆盖内容 | 示例 |
|------|---------|------|
| 正常路径 | 典型输入、预期输出 | 合法参数 → 正确结果 |
| 边界条件 | 空值、极值、特殊值 | 空列表、0、None、超大数值 |
| 异常场景 | 错误输入、依赖失败 | 非法参数异常、网络超时 |
| 边缘情况 | 竞态条件、并发 | 重复调用、同时修改 |

### 3. 输出测试代码
- 使用项目已有的测试框架（pytest / jest / unittest 等）
- 遵循项目已有的测试命名约定和目录结构
- 每个用例包含 Arrange-Act-Assert 三段式结构
- 对外部依赖使用 mock/stub 隔离

## 输出规范

```python
# 文件: tests/test_<module>.py

def test_<function>_<scenario>():
    """测试 <场景描述>"""
    # Arrange
    # Act
    # Assert
```
