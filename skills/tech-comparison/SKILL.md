# 技术对比技能

## 功能

从多个维度系统性地比较两项或多项技术方案，输出结构化的对比报告，帮助做出技术选型决策。

## 对比维度

### 1. 基础信息
| 维度 | 方案 A | 方案 B |
|------|--------|--------|
| 名称 | | |
| 版本 | | |
| 许可证 | | |
| 语言/平台 | | |
| 首次发布 | | |

### 2. 功能对比
- 核心功能覆盖度（支持 vs 不支持 vs 部分支持）
- 扩展性 / 插件生态
- 与现有技术栈的兼容性

### 3. 非功能特性
- **性能**：基准测试数据（如有）、吞吐量、延迟
- **可扩展性**：水平扩展能力、集群支持
- **可靠性**：生产部署案例、故障率、SLA

### 4. 社区与生态
- GitHub Stars / Contributors / Commits 趋势
- 包下载量（npm / PyPI / Maven 等）
- 文档质量、教程资源、Stack Overflow 问题数
- 主要采用公司 / 项目

### 5. 运维成本
- 学习曲线（新手入门时间）
- 部署复杂度
- 监控 / 日志 / 告警支持度

## 输出规范

```
# 技术对比报告：<主题>

## 摘要
<一句话结论>

## 详细对比
| 维度 | <方案A> | <方案B> |
|------|---------|---------|
| ... | ... | ... |

## 推荐建议
- **如果... → 选 A**
- **如果... → 选 B**
- **如果预算/团队/时间有限 → 选 ...**

## 参考资料
1. [标题](链接)
2. [标题](链接)
```
