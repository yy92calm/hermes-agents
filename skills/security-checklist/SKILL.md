# 安全审查清单技能

## 功能

按照安全审查清单逐项检查代码，发现安全漏洞、配置缺陷和敏感信息泄露等问题。

## 审查清单

### 1. 注入攻击（SQL / NoSQL / 命令 / LDAP）
- [ ] 用户输入是否经过参数化查询或转义？
- [ ] ORM 框架是否存在原生 SQL 拼接？
- [ ] 是否存在 eval() / exec() / os.system() 等危险调用？

### 2. 认证与会话管理
- [ ] 密码是否使用强哈希算法（bcrypt / argon2）存储？
- [ ] Token（JWT / Session）是否有合理的过期时间？
- [ ] Token 签名密钥是否硬编码在代码中？

### 3. 敏感数据泄露
- [ ] 日志中是否可能输出密码、Token、密钥？
- [ ] .env / .gitignore 是否正确排除了密钥文件？
- [ ] API 响应是否返回了不应暴露的内部信息（堆栈跟踪、数据库错误）？

### 4. 访问控制
- [ ] 是否存在越权访问漏洞（IDOR）？
- [ ] 权限检查是否在服务端而非仅客户端执行？
- [ ] 管理员接口是否有额外的访问限制？

### 5. 文件上传与路径遍历
- [ ] 上传文件类型是否有白名单限制？
- [ ] 文件名是否经过安全处理（防止路径遍历）？
- [ ] 上传目录是否禁止脚本执行？

### 6. 依赖与第三方库
- [ ] 是否存在已知漏洞的依赖版本？
- [ ] package.json / requirements.txt 中是否指定了版本范围而非固定版本？

### 7. 配置与环境
- [ ] 调试模式是否在生产环境关闭？
- [ ] CORS 配置是否过于宽松？
- [ ] HTTPS 是否强制开启？

## 输出规范

```
## [严重] 安全问题标题
- **文件**: path/to/file.ext:L123
- **风险**: 说明
- **修复建议**: 具体修改方案
```
